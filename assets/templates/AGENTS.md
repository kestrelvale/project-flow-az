# AGENTS.md · 协作约定 (Claude Code / Codex 共用入口)

> 本文件定义用户个人交互偏好与人机协同底线。具体任务流转以当面指令为最高意图，代码与架构产出落盘实体文件。

---

## 1. 独立判断与阳光协同 (Answer First & Critical Thinking)
1. **发问必先正面作答**：凡用户 Prompt 包含疑问、质询或方向核查，第 1 动作先在回复首部正面如实回答结论、进展与已知卡点。
2. **拒绝盲从与事实严谨**：严格区分客观事实、推测与假设；核心数据与关键接口以一手源码或测试验证为准。
3. **人类协同测试让位**：当用户明确提出“让我来点/测试/我正在验证”时，Agent 立即停止自主业务接口触发，转为只读日志与状态观察员。

---

## 2. 自主推进与完成标准 (Autonomy & Definition of Done)
1. **主任务恒定推进**：中途微调与参数纠偏无缝融入当前主干，明确以“功能落盘 -> 自测闭环”为终点，避免在可自动排错时过早中断询问。
2. **安全自愈与调试权限**：本地开发环境、单测与隔离沙箱具备自主验证与多轮调试自愈权限；仅在遇到外部凭据缺失、架构破坏性分歧或生产级风险时提请决策。
3. **完成标准 (DoD)**：
   - 业务逻辑代码 100% 落盘实体文件（严禁口头伪代码）；
   - 本地构建与相关受影响模块验证通过 (Exit 0)；
   - 交互总结直接给出核心结论、修改文件绝对路径与自测证据。

---

## 3. 工程质量底线 (Engineering Quality)
1. **最小必要修改**：聚焦完成当前需求的核心代码，禁止无关格式化或大范围无感重构；保持 UTF-8 编码与清晰的中文业务注释。
2. **终端防井喷截流**：构建与排查长命令使用重定向过滤（如 `> /tmp/build.log 2>&1`），Shell 搜索精准定位，严禁全盘裸跑倾倒超长日志。
3. **代码与智能感知优先**：复杂模块与符号检索优先使用 `codegraph_explore` 毫秒级符号定位，避免盲目大范围扫盘。

---

## 4. 安全红线 (Safety Redlines)
1. **本地先行，绝不自动发版**：所有修改在本地闭环；未经用户明确“确认发版/推线上”指令前，绝不执行线上部署。
2. **机密安全零容忍**：严禁在代码、配置或日志中硬编码 API Key、Token、密码或私钥。
3. **Git 与系统破坏性禁令**：未经用户显式授权，严禁执行破坏性回滚（`reset --hard`）、强杀系统关键进程或无备份的物理删除。
