# 驱动模式与验证策略（按需加载）

本文件只在当前任务需要规格、测试或验收设计时加载，不把完整流程注入每一轮上下文。

## 四阶段与模式对齐（唯一映射）

| 项目阶段 | 计划模式 | 驱动模式 | 任务卡 `mode` | 该阶段职责 |
|---|---|---|---|---|
| 项目初期 | Plan / Goal | SDD | `plan` | 定目标、锁规格、拆原子任务，只读不改业务代码 |
| 实现期 | - | TDD | `execute` | 先写失败测试，再最小实现使其通过 |
| 验收期 | - | ATDD | `review` | 把验收标准转成可执行断言并留证据 |
| 收尾期 | - | BDD | `handoff` | Given-When-Then 描述行为，交接下一步 |

阶段单向流转：`plan -> execute -> review -> handoff`。每进入下一阶段只改任务卡 `mode` 与 `method` 并补齐该阶段必填字段，不得跳阶段或回退冒充。

## 路由

| 任务类型 | 默认驱动链 | 最小产物 |
|---|---|---|
| 新功能、接口、状态流转 | SDD -> TDD -> ATDD -> BDD | 规格契约、失败测试、验收断言、Given-When-Then |
| Bug 修复 | Reproduce -> TDD -> ATDD | 最小复现、回归测试、真实流程验证 |
| UI / 交互改造 | SDD -> ATDD -> BDD | 状态与边界规格、端到端检查、人工体验步骤 |
| 重构 | SDD -> TDD | 行为契约、重构前后测试一致 |
| 调研 / 内容 / 方案 | SDD -> 评审门 | 范围、来源、结论、反证与交付路径 |
| 架构 / 复杂流程 | SDD -> Plan Mode -> TDD/ATDD | 规格、计划、边界测试与验收 |

## SDD

动手前写清输入、输出、边界和失败状态。复杂任务在 `flow/plan.md` 拆成 P0-x 原子项，并锁定写入白名单。

## TDD

代码任务先留下一个能因缺陷而失败的检查，再做最小实现使其通过。单点逻辑优先小脚本或现有测试框架，不新增重型依赖。

## ATDD

把验收标准转成可执行的接口、端到端或脚本断言。没有自动化条件的界面任务，至少留下可复现命令与明确观测点。

## BDD

人工验收项使用 Given-When-Then 描述用户可见行为，避免“已实现”“应该可用”这类无证据结论。

## Plan 模式

`Plan` 是计划模式。复杂任务先交给 Codex Plan Mode 做只读拆解；计划门禁通过后才切换 Execute Mode。

详细交接规则见《计划模式交接SOP.md》。

## 停止条件

- 无规格、无验证或验证失败：不得标记 `[-]` 待验收。
- 同一构建或排查连续失败 2 次：停止试错并暴露阻塞点。
- 当前任务完成后检查审计输出，未处理的历史债务保持可见，但不自动越权施工。

## v2 严格门禁：把模式从“标签”变成“产物”

`schema: v2` 的任务卡由 `flow-gate.py` 校验**真实产物**，而不是字段里有没有那个词。老卡（无 `schema` 字段）继续走宽松规则，不破坏在途任务。

| 阶段 | 模式 | v2 强制产物 | 缺失后果 |
|---|---|---|---|
| plan | Plan / Goal / SDD | `scope` 必须写全**输入、输出、边界**三段 | 门禁 FAIL：规格不完整，无法据以拆解 |
| execute | TDD | `red_test` 指向**真实存在**的失败测试文件 | 门禁 FAIL：无法证明先红后绿 |
| review | ATDD | `evidence` 指向**真实存在**的证据文件 | 门禁 FAIL：不接受口头“已验证” |
| review/handoff | BDD | `acceptance` 必须是 **Given-When-Then** | 门禁 FAIL：无法用可观测行为验收 |

### 为什么是产物而不是文字

旧实现只检查 `method` 字段是否包含 `TDD` 这样的字符串。实测可以造出一张完全没有测试的卡，只要写上 `method: TDD` 就能通过门禁——**理论沦为标签，Agent 每次自行发挥**。

v2 把每个模式绑定到磁盘上必须存在的文件或结构：

- 写 `TDD` 就必须交出一个真实测试文件；
- 写 `ATDD` 就必须交出一份真实证据文件；
- 写 `BDD` 就必须给出 Given-When-Then。

**门禁能验证的才叫约束，验证不了的只是建议。**
