# 正杰全球聘 · 工作区与根目录零污染治理规范 (Zero Root Clutter SOP)

> **核心定位**：彻底根治开发过程中临时文件、测试脚本、排查截图与单次日志随意堆放根目录的痼疾，建立长效的工作区清洁网与白名单准入防护机制。

---

## 1. 根目录白名单准入机制 (Root Whitelist)

根目录下**仅允许**存在以下 4 类必要文件，其余任何临时或过程文件一律禁止直接落地根目录：

| 分类 | 允许存在的文件 / 软链 | 说明 |
| :--- | :--- | :--- |
| **项目规则与说明** | `AGENTS.md`, `CLAUDE.md`, `CHANGELOG.md`, `.gitignore`, `.codegraphignore` | Agent 与开发者通用规则入口及全局变更日志 |
| **核心前端入口** | `index.html`, `feedback-dashboard.html`, `feedback-collector.js`, `checking.html`, `html2canvas.min.js` | 五端专属演示中心、排障中枢大盘与通用采集探针 |
| **服务控制入口** | `start.sh`, `status.sh`, `stop.sh`, `server.pid` | 根目录便捷快捷方式（软链至 `scripts/`）及守护进程 PID 标识 |
| **核心业务软链** | `B端企业小程序端`, `B端企业端-Web管理后台`, `C端人才经纪人小程序端`, `公共验收大厅`, `平台运营端`, `求职者小程序端` | 指向真实版本发布目录的快捷软链 |

---

## 2. 过程性与临时文件标准收纳路径 (Transient Artifact Routing)

开发与排障过程中产生的中间产物，必须严格遵从以下路由规则，**严禁落在根目录**：

```
zhengjie-hrm/
├── archive/
│   ├── test-screenshots/    # [必须] 自动化测试与走查截图 (*.png, *_crop.png)
│   ├── test-scripts/        # [必须] 一次性走查、按钮检查、微单测脚本 (*.js, *.py)
│   ├── deploy-scripts/      # [必须] 阶段性发版与部署补丁脚本
│   └── misc-tools/          # [必须] 一次性结构修复与批量替换工具
├── docs/
│   ├── archive/
│   │   ├── feedback-reports/  # [必须] 历史单工单/缺陷修复交付报告 (FB-*.md)
│   │   ├── milestone-reports/ # [必须] 阶段性走查、多端闭环与改版交付报告
│   │   └── superseded-specs/  # [必须] 已废弃或过时的历史工作流草稿
│   └── 项目日报/              # [必须] 纯 Markdown 日报文档
└── logs/                    # [必须] 服务运行与单次测试日志 (*.log)
```

### 详细落盘禁令与重定向规则：

1. **测试与排障截图禁令**：
   - 严禁在根目录生成 `*.png`、`*.jpg` 或 `*_crop.png`；
   - 走查与测试截图必须直接保存到 `archive/test-screenshots/`；仅作临时核对的图片在核对完成后必须**立即物理删除**。
2. **一次性测试/探测脚本禁令**：
   - 严禁在根目录编写 `test_*.js`、`check_*.py`、`verify_*.sh` 等脚本；
   - 测试脚本一律放在 `archive/test-scripts/` 或执行完成后当场物理销毁（即用即删）。
3. **调试与运行日志禁令**：
   - 严禁在根目录重定向生成 `test.log`、`server.log`、`debug.log`；
   - 后台进程日志统一重定向至 `/dev/null` 或专有 `logs/` 目录，单次排查使用内存管道或直接查看控制台输出。
4. **一次性修复/打补丁脚本禁令**：
   - 严禁在根目录残留 `patch_*.py`、`fix_*.py`、`update_*.js` 等一次性工具；
   - 执行完毕后立即移入 `archive/misc-tools/` 或彻底清除。
5. **文档分类落盘规范**：
   - 长效规范与架构设计必须落在 `docs/` 根层；
   - 单个工单或缺陷修复报告必须落在 `docs/archive/feedback-reports/`；
   - 严禁在根目录随意抛洒临时 `.md` 或 `.html`。

---

## 3. 收工前根目录反查自检门禁 (Pre-Stop Sanitation Check)

每次会话收工前，Agent 必须执行根目录白名单自检反查：

```bash
# 根目录清洁度反查单行命令
ls -la | grep -E '\.(png|jpg|log|tmp)$|^test_|^check_|^patch_|^FB-'
```

- 若发现任何匹配项，**严禁宣告任务完结**，必须先物理清理或归位至 `archive/` 对应目录；
- 确保根目录随时保持纯净、标准、零噪声。
